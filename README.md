# 烟花燃放联锁台（hxyfront-62008）

单页烟花燃放联锁台，React + Vite + TypeScript。面向编排师登记点火节点，按实时风向做
爆开范围推演与联锁校验，全部通过后才允许生成逐发预演。数据存 localStorage，刷新保留。

## 预设原脚本（只读，操作员不可改动）

- 4 个发射点：LP-1 东台、LP-2 西台、LP-3 北岸地、LP-4 南岸地
- 3 段节目：序幕 00:00–01:00、主章 01:00–02:30、终章 02:30–04:00
- 2 块圆形临时禁放区：临时观礼台区、器材堆放区

## 点火登记字段

方位角（罗盘角，0°=北/90°=东）、点火时刻（mm:ss.mmm）、飞行时长（秒）、扩散半径（米）。

爆开模型：`爆开圆心 = 发射点 + 方位角方向 ×(20 m/s × 飞行时长) + 风偏(风向 × 风速 × 飞行时长)`。

## 联锁规则（批次提交时任一发违规即整批拒绝）

1. 爆开范围（扩散圆）侵入任一临时禁放区；
2. 同一点位与前一发的点火间隔不足 1 秒；
3. 点火时刻早于节目段开场，或点火 + 飞行越过节目段结束。

调整某发方位角后，联锁台只重算该点位的后续节点（见 `rules.ts` 的
`downstreamNodeIds / reevaluateFrom`），重算通过才能生成预演。

## 代码结构（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 预设数据、几何/风偏计算、三类联锁规则、增量重算、整批提交 |
| `src/storage.ts` | 点火节点 / 待提交批次 / 风向的 localStorage 持久化与恢复 |
| `src/PointMap.tsx` | 点位平面图 SVG：禁放区、弹道、风偏爆开范围、预演动画 |

`src/App.tsx` 只负责页面编排与交互状态，不含业务判定。
